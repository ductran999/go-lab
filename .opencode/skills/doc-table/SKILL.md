# Doc table

Research notes are decided by scanning, not reading. Tables over
headlines, one idea exactly once.

1. Open with a TL;DR blockquote (3-4 lines, bold keywords).
2. Content lives in tables. Prefer one table with rows per item
   and columns `Use for | What it tells | How to use`.
3. Add a `Reads as` column when each row needs a one-line mental
   model (e.g. counter: what happened, gauge: the state right now).
4. Tradeoffs go `✅ Gain | 🪙 Price`; mistakes go
   `❌ Cause → consequence | ✅ Instead`. Keep cells under ~15
   words; 2-4 words per cell when the table is for scanning.
5. Sections are numbered and few (Why → Tradeoff → Matrix →
   Cause). If a section's every row already lives in another
   table, delete the section.
6. Docs and code comments are 100% English. Conversation stays
   out of the files.
7. Lab docs end with an `In this lab` mapping table
   (piece → metric/endpoint/proof command).
